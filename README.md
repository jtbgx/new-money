# New Money · 股市启蒙实验室

给第一次接触股市的人做交互式金融知识学习。这里不推荐股票，只提供认知工具。

## 当前状态

这是项目的初始前端环境，已经包含：

- 可运行的本地静态服务器
- 课程地图与五节主课骨架
- 学习进度本地保存
- 响应式布局

课程内容将逐步填充为可互动实验。

## 运行

需要 Node.js 18 或更高版本。

```powershell
npm start
```

然后打开浏览器访问：

```text
http://localhost:4173
```

如果只需要本地预览，也可以直接打开 `public/index.html`。
